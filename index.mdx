Eo Poker is a real-time multiplayer poker variant built with React 19, Vite, and Firebase Firestore. Instead of chips and blinds, every round revolves around a single shared **Confidence** value from 1 to 10. Win the round and you gain that many points; lose a showdown and you lose them. First player to **50 points** wins the game.

Play it live at [ego-demo.web.app](https://ego-demo.web.app/).

## What makes it different

- **All five community cards are dealt face up at once.** There is no flop, turn, or river — you see the full board before anyone acts.
- **Confidence replaces the pot.** Raising means declaring a higher confidence (up to 10) that your two hole cards beat everyone else's on the shared board.
- **Symmetric stakes.** At showdown, winners gain the confidence value and every losing player who stayed in loses the same amount. Folding costs nothing.

## Tech stack

| Layer | Technology |
| --- | --- |
| Frontend | React 19 \+ Vite 7 |
| Backend | Firebase Firestore (serverless, no custom server) |
| Hand evaluation | [`pokersolver`](https://www.npmjs.com/package/pokersolver) |
| State | React hooks \+ Firestore `onSnapshot` subscriptions |
| Hosting | Firebase Hosting with GitHub Actions CI |

</Note>
