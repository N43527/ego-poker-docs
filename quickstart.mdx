## Play online

The fastest way to try Ego Poker is the hosted demo.

<Steps>
  <Step title="Open the Game Hub">
    Go to [https://ego-demo.web.app/](https://ego-demo.web.app/) and choose **EGO Poker**.
  </Step>
  <Step title="Register a profile">
    Enter a name and a passkey, then click **Register**. Your profile is tied to a device ID stored in `localStorage`; the passkey lets you reconnect to the same profile from another device with **Reconnect**.
  </Step>
  <Step title="Create or join a game">
    Click **Create Game** to get a 4-character lobby code, or paste a friend's code and click **Join Game**. Share the code shown in the sidebar to invite others.
  </Step>
  <Step title="Start playing">
    The host clicks **START GAME** once everyone is in. Cards are dealt instantly and play proceeds in turns — see [How to Play](/how-to-play).
  </Step>
</Steps>

<Note>
  Lobby codes are 4 characters drawn from letters and digits (base-36), so a code like `K3ZQ` is valid — they are not strictly letters.
</Note>

## Run locally

Requires Node.js (the CI pipeline uses Node 20) and npm.

<Steps>
  <Step title="Install dependencies">
    ```bash
    npm install
    ```
  </Step>
  <Step title="Start the dev server">
    ```bash
    npm run dev
    ```

    Vite serves the app with hot module replacement, by default at `http://localhost:5173`.
  </Step>
  <Step title="Build for production">
    ```bash
    npm run build
    ```

    Output lands in `dist/`, which is what Firebase Hosting serves. Preview the production build with `npm run preview`.
  </Step>
</Steps>

<Warning>
  The local build connects to the **production** Firebase project (`ego-demo`) — the Firestore config is hardcoded in `src/firebase.js`. Games you create locally are real games on the live backend. To develop against your own backend, swap in your own Firebase project config. See [Development Setup](/development/setup).
</Warning>
