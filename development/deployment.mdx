The app deploys to **Firebase Hosting** at [ego-demo.web.app](https://ego-demo.web.app/), with automated deploys on merge and PR preview channels via GitHub Actions.

## Hosting configuration

`firebase.json` serves the Vite build output and rewrites every route to `index.html` (the app is a single-page app with in-memory routing):

```json firebase.json
{
  "hosting": {
    "public": "dist",
    "ignore": ["firebase.json", "**/.*", "**/node_modules/**"],
    "rewrites": [{ "source": "**", "destination": "/index.html" }]
  }
}
```

`.firebaserc` pins the default project:

```json .firebaserc
{
  "projects": {
    "default": "ego-demo"
  }
}
```

## Manual deploy

```bash
npm run build
firebase deploy --only hosting
```

Requires the Firebase CLI (`npm i -g firebase-tools`) and `firebase login` with access to the target project.

## CI: deploy on merge

`.github/workflows/firebase-hosting-merge.yml` (auto-generated by the Firebase CLI) deploys to the **live** channel on every push to `main`:

<Steps>
  <Step title="Checkout and toolchain">
    `actions/checkout@v4` and `actions/setup-node@v4` with **Node 20**.
  </Step>
  <Step title="Install and build">
    `npm ci` followed by `npm run build`.
  </Step>
  <Step title="Deploy">
    `FirebaseExtended/action-hosting-deploy@v0` with `channelId: live` and `projectId: ego-demo`, authenticated via the `FIREBASE_SERVICE_ACCOUNT_EGO_DEMO` repository secret.
  </Step>
</Steps>

## CI: PR preview channels

`.github/workflows/firebase-hosting-pull-request.yml` runs on every pull request from the same repository (`github.event.pull_request.head.repo.full_name == github.repository`, so forks are excluded). It builds and deploys to a temporary **preview channel**, and the action comments the preview URL on the PR (it has `pull-requests: write` permission).

<Warning>
The PR workflow runs `npm run build` **without a prior `npm ci` or `setup-node` step**, unlike the merge workflow. It will fail on a fresh runner unless dependencies are cached or the step is added — if PR previews break with module-not-found errors, add the install step to match the merge workflow.
</Warning>

## Secrets

| Secret | Purpose |
| --- | --- |
| `FIREBASE_SERVICE_ACCOUNT_EGO_DEMO` | Service-account JSON used by `action-hosting-deploy` to deploy to the `ego-demo` project |
| `GITHUB_TOKEN` | Built-in token, used by the action to post PR preview comments and checks |

<Note>
The Firebase **web app config** in `src/firebase.js` (API key, project ID, etc.) is not a secret — it is shipped to every browser by design. Backend protection must come from Firestore security rules, not from hiding the config.
</Note>
